# Privacy policy — PMP Coach by Anh Vu

**Draft for Anh Vu's review; not an active policy.** Prepared 2026-11-09. Confirm the support-data practices below before publication and choose an effective date.

## Scope and publisher

PMP Coach by Anh Vu is an independent educational plugin maintained by Anh Vu. Its source is https://github.com/anhvu-pm/pmpskill. This policy describes the plugin and the project's support channel, not OpenAI's or GitHub's services.

## Conversations and the plugin package

The current package contains coaching instructions, reference documents, and an icon. It has no MCP server, separate learner account system, analytics code, or payment integration. The package does not itself send your questions, uploaded images, answers, or conversations to a server operated by Anh Vu.

When you use the plugin in ChatGPT or Codex, OpenAI processes your input under its own terms, privacy policy, and your account or workspace settings. This policy does not promise that your conversations are never stored or used by OpenAI. Consult https://openai.com/policies/privacy-policy/ and your product's data controls.

If you deliberately configure additional tools or private resources, their access and data handling are governed by those tools and your configuration; they are not required to use this public skill.

## Support information

Proposed practice for owner confirmation: when you voluntarily open a GitHub Issue, Anh Vu uses your GitHub username, issue text, attachments, and replies to answer the request and improve the project. The project does not request a full conversation history, learner records, or account credentials.

GitHub Issues are public. Other people can read, copy, or index information you publish there. GitHub also processes data under its own privacy statement: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement.

Proposed retention for owner confirmation: support issues remain in the repository until removed; closing an issue does not delete it. Confirm whether Anh Vu keeps any separate support records or copies and, if so, their retention and deletion process before publishing this policy.
