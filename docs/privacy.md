# Privacy policy — PMP Coach by Anh Vu

Effective date: 2026-11-09.

## Scope and publisher

PMP Coach by Anh Vu is an independent educational plugin maintained by Anh Vu. Its source is https://github.com/anhvu-pm/pmpskill. This policy describes the plugin and the project's support channel, not OpenAI's or GitHub's services.

## Conversations and the plugin package

The current package contains coaching instructions, reference documents, and an icon. It has no MCP server, separate learner account system, analytics code, or payment integration. The package does not itself send your questions, uploaded images, answers, or conversations to a server operated by Anh Vu.

When you use the plugin in ChatGPT or Codex, OpenAI processes your input under its own terms, privacy policy, and your account or workspace settings. This policy does not promise that your conversations are never stored or used by OpenAI. Consult https://openai.com/policies/privacy-policy/ and your product's data controls.

If you deliberately configure additional tools or private resources, their access and data handling are governed by those tools and your configuration; they are not required to use this public skill.

## Support information

GitHub Issues are the sole project support channel. When you voluntarily open a GitHub Issue, Anh Vu uses your GitHub username, issue text, attachments, and replies to answer the request and improve the project. The project does not request a full conversation history, learner records, or account credentials.

GitHub Issues are public. Other people can read, copy, or index information you publish there. GitHub also processes data under its own privacy statement: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement.

Support information is handled through GitHub Issues. Issues and replies remain in the repository until removed; closing an issue does not delete it. GitHub may retain information under its own privacy policy. Public copies made by other people are outside the project’s control.

## Choices and removal

Share only the minimum information needed for help. Redact names, grades, employer details, and unrelated content; use original or authorized examples. You can edit or delete your own content where GitHub permits it and use https://support.github.com/contact/privacy for GitHub privacy requests.

To request removal of information from a project issue, contact Anh Vu through GitHub Issues. Identify the affected issue or comment without repeating personal information. Removal from the repository cannot guarantee removal of copies held by GitHub or third parties.

## Changes and contact

Changes to this policy will be recorded on this page with an updated effective date. Support and privacy requests: https://github.com/anhvu-pm/pmpskill/issues.
