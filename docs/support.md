# Support — PMP Coach by Anh Vu

PMP Coach by Anh Vu helps learners review individual PMP practice questions in Vietnamese. The project is maintained by Anh Vu in the [pmpskill repository](https://github.com/anhvu-pm/pmpskill).

## Get help or report a problem

[Open a GitHub Issue](https://github.com/anhvu-pm/pmpskill/issues/new) for installation problems, unclear explanations, disputed reasoning, or suggestions. A GitHub account is needed to open an issue. Check [existing issues](https://github.com/anhvu-pm/pmpskill/issues) first.

Include the plugin version, whether you use ChatGPT or Codex, what you expected, and what happened. For reasoning feedback, explain the point of disagreement and provide only an original or authorized, anonymized example.

**Issues are public.** Do not post passwords, account details, learner names, grades, private conversations, employer information, or copyrighted exam-bank material. Crop and redact screenshots before posting. You do not need to share a full chat history.

For an issue containing personal information, remove or edit your own content where GitHub permits it. You can also use [GitHub's privacy support](https://support.github.com/contact/privacy). Do not repeat the information in a new public issue.

## Installation status

The repository provides the source and local installation instructions. A public OpenAI directory installation link has not yet been verified. Follow the [README](../README.md) for the currently documented installation methods.

## Learning limitations

AI explanations can be wrong. Compare them with the question and your authorized study materials. This independent project is not affiliated with or endorsed by PMI and does not guarantee an exam result.
